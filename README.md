# 📚 BookNook – Online Library Management System

**BookNook** is a modern online library management platform that makes discovering, managing, and borrowing books easier. Users can explore available books, borrow their favorite titles, manage their personal library, and keep track of borrowed books through a clean and user-friendly interface.

**Live Site:** [Visit BookNook](YOUR_LIVE_SITE_URL)

## ✨ Key Features

- **Browse Books:** Explore a collection of books and discover different categories, including Fiction, Science, History, Technology, and more.
- **Book Details:** View detailed information about each book, including its title, author, description, category, and available copies.
- **Borrow Books:** Logged-in users can borrow available books and receive an expected return date.
- **My Borrowed Books:** Manage borrowed books and return them when finished.
- **Add New Books:** Users can add new books to the library with relevant information and images.
- **Manage Your Books:** Update or delete books that you have added.
- **User Authentication:** Secure authentication allows users to access personalized features.
- **Profile Dashboard:** View profile information, total added books, and borrowed book statistics.
- **Responsive Design:** Enjoy a smooth browsing experience across desktop, tablet, and mobile devices.
- **Smooth Scrolling:** Lenis provides a smoother scrolling experience throughout the website.
